Murtaza SEO Tools

A collection of browser-based tools for converting rich text into clean HTML, compressing images to a target size, and batch-converting image formats with individual or ZIP downloads. Your files stay on your device.

Rich Text → Clean HTML

Convert pasted Word or Google Docs content into lightweight HTML with bold text, hyperlinks, images, and line breaks.

Click below, then use Ctrl+V or the browser’s normal right-click Paste. Bold text and linked text are retained.

No-Save Image Compressor

Reduce an image to a target file size in KB or MB, then preview and download the compressed result.

Your image stays on this device. Choose it, select a compression level, then download the compressed JPEG.

Choose an image to begin.

Batch Image Format Converter

Convert multiple images to PNG, JPEG, JPG, or WebP and download each file individually or together as a ZIP.

Convert as many images as you need, locally in your browser. Files are not uploaded or saved by this tool. Animated GIFs convert as a still image.

Choose images to begin.

Image Resizer

Resize an image to exact pixel dimensions, then preview and download the result.

Your image stays on this device. Choose it, set the new width and height, then download the resized image.

Choose an image to begin.

Background Remover

Remove the background from a photo, then keep it transparent or swap in a solid color.

Background removal runs on-device using an AI model downloaded the first time you use it (needs an internet connection once; cached after that). Your image itself is never uploaded.

Choose an image to begin.
